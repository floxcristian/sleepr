## Paso 1: Crear un proyecto de Google Cloud (opcional)

- Haz clic en el botón **Proyecto nuevo**:

<img src="/docs/images/gcp/new_project.png">

- Ingresa el nombre y organización:

<img src="/docs/images/gcp/new_project_name.png">

- Selecciona el proyecto que acabas de crear:

<img src="/docs/images/gcp/select_new_project.png">

## Paso 2: Crear un repositorio de Google Cloud Artifact Registry

- En la parte superior busca y selecciona **Artifact Registry**:

<img src="/docs/images/gcp/search_artifact_registry.png">

- Habilitemos el **API de Google Container Registry**:

<img src="/docs/images/gcp/enable_api_ar.png">

- Luego hagamos click en **Crear repositorio**:

<img src="/docs/images/gcp/create_repository.png">

- Aquí deberíamos crear uno para cada microservicio o app. Seleccionamos la región que mas nos convenga. En el caso de Chile y Perú podríamos seleccionar Santiago:

<img src="/docs/images/gcp/creating_repository.png">

Una vez creado el repositorio nos debería aparecer en la sección repositorios:

<img src="/docs/images/gcp/repository_created.png">
